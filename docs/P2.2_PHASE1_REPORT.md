## 1. Scope & Objective
Phase 1 implements read-only user collection/board list discovery against the existing browser session (`.xhs-profile`), writing immutable evidence snapshots into `knowledge/collections/`.

### Constraints Enforced
- ✅ Zero modifications to P1 (`src/xhs_ingest/`, `StateStore`, `sync.db`, `data/`).
- ✅ Zero modifications to Exporter or Obsidian `Vault/`.
- ✅ No fetching of board notes, note details, or media assets.
- ✅ Fail-closed behavior on unauthenticated sessions, schema anomalies, and unproven empty collections.

---

## 2. Artifacts Produced

### A. Core Package (`src/xhs_collection_importer/`)
- `src/xhs_collection_importer/models.py`: `BoardMeta` and `CollectionSnapshot` data classes.
- `src/xhs_collection_importer/discovery.py`: `CollectionDiscovery` implementation with:
  - Persistent Playwright session management.
  - Multi-channel resilient extraction:
    - Network interception (`/api/sns/web/v1/board/user`)
    - Client state (`window.__INITIAL_STATE__.board.userBoardList`)
    - DOM board cards (`a.board-card, a[href*='/board/']`) cross-validated with tab counts.
  - Strict empty-state proof requirement (`专辑・0` / empty indicators).
  - Atomic file writes (`.tmp` staging + atomic rename).
- `src/xhs_collection_importer/__main__.py`: CLI discovery interface (`python -m xhs_collection_importer discover`).
