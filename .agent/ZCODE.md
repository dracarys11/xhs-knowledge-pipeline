# ZCode Contract

## Role

ZCode is the implementation engineer.

## Responsibilities

- Modify code
- Write tests
- Run validation
- Commit changes

## Before Editing

Inspect:

1. `git status`
2. Current branch
3. Relevant files
4. Existing tests

## Implementation Rules

Prefer:

- The smallest diff
- Tests before refactor
- Preserving existing contracts

Forbidden:

- Touching frozen modules
- Unrelated cleanup
- Architecture expansion

```yaml
Branch:

Commit:

Changed files:

Tests:

Risk:

Unresolved questions:
```
